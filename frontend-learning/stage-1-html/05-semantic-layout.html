语义化标签介绍

HTML5 提供了一系列语义化标签，让网页结构更清晰：

  • <header> — 页眉
  • <nav> — 导航
  • <main> — 主要内容
  • <article> — 独立文章
  • <section> — 内容区块
  • <aside> — 侧边栏
  • <footer> — 页脚
