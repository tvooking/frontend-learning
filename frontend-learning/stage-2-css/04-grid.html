📊 Grid vs Flexbox 怎么选？

  • Flexbox — 一维布局（行 或 列），适合导航栏、卡片行
  • Grid — 二维布局（行和列同时），适合页面整体框架、照片墙
  • 两者结合 — 外层用 Grid 布局页面，内部用 Flexbox 排细节
