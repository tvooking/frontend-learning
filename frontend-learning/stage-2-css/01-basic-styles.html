常用 CSS 属性

属性作用示例值
color文字颜色red, #333, rgb(255,0,0)
font-size字号16px, 1.2em
background-color背景色#f0f0f0
border边框1px solid #ccc
border-radius圆角8px, 50%（圆形）
padding内边距10px 20px
margin外边距0 auto（居中）
box-shadow阴影2px 2px 5px rgba(0,0,0,0.3)

三种写 CSS 的方式

  1. 行内样式 — 在标签的 style 属性中（优先级最高）
  2. 内部样式 — 在 <style> 标签中（本文件的方式）
  3. 外部样式 — 单独的 .css 文件（最推荐，下一课会用到）
