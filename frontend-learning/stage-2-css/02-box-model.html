📦 盒模型（Box Model）

盒模型结构

  ┌─────────────────────────────┐  ← margin (外边距)
  │  ┌───────────────────────┐  │
  │  │  border (边框)         │  │
  │  │  ┌─────────────────┐  │  │
  │  │  │  padding (内边距) │  │  │
  │  │  │  ┌───────────┐  │  │  │
  │  │  │  │ 内容区     │  │  │  │
  │  │  │  │ (content)  │  │  │  │
  │  │  │  └───────────┘  │  │  │
  │  │  └─────────────────┘  │  │
  │  └───────────────────────┘  │
  └─────────────────────────────┘

实际演示

内容区 200×100
padding: 20
border: 5
margin: 30

实际占位 = 200 + 20×2 + 5×2 + 30×2 = 310px 宽

content-box vs border-box

content-box（默认）
宽 = 200 + 40 + 10 = 250px
border-box
宽 = 200px（含 padding 和 border）

💡 推荐：全局设置 box-sizing: border-box，布局更好控制。

display 属性

  • block — 块级元素，独占一行（div, h1, p）
  • inline — 行内元素，不换行（span, a, strong）
  • inline-block — 行内块级（既有宽高又不换行）
  • none — 隐藏元素
