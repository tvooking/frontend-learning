📌 响应式设计三要素

  1. viewport 设置 — <meta name="viewport" content="width=device-width, initial-scale=1.0">
  2. 弹性布局 — 使用 %、fr、flex 等相对单位
  3. 媒体查询 — @media (max-width: 768px) 在不同屏幕宽度下应用不同样式

💡 常用断点

  • 手机：max-width: 480px
  • 平板：max-width: 768px
  • 笔记本：max-width: 1024px
  • 桌面：1024px 以上
