📝 JavaScript 变量与数据类型

打开控制台查看效果

按 F12 或 Ctrl+Shift+I → 点 Console（控制台）

声明变量

// let — 可以重新赋值（推荐）
let name = "小明";
name = "小红";  // ✅ 可以改

// const — 常量，不能改（推荐）
const birthday = "2000-01-01";
// birthday = "2001-01-01";  // ❌ 会报错

// var — 旧方式（不推荐）
var oldWay = "过时的写法";

数据类型

// 字符串 (String)
let city = "北京";

// 数字 (Number)
let age = 25;
let price = 19.9;

// 布尔值 (Boolean)
let isStudent = true;
let isWorking = false;

// 数组 (Array) — 列表
let fruits = ["苹果", "香蕉", "橙子"];

// 对象 (Object) — 键值对
let person = {
  name: "小明",
  age: 25,
  city: "北京"
};

// 查看类型
console.log(typeof "hello");  // "string"
console.log(typeof 42);       // "number"
console.log(typeof true);     // "boolean"
console.log(typeof []);       // "object"
