🌐 Fetch API 与数据交互

📡 什么是 API？

API（应用程序接口）就像餐厅的菜单——你告诉餐厅你要什么，他们给你做好端上来。

在前端开发中，我们通过 API 从服务器获取数据（JSON 格式）。

// JSON 数据格式示例
{
  "userId": 1,
  "id": 1,
  "title": "学习 Fetch API",
  "completed": false
}

📥 fetch() — 获取数据

// 基本使用
const response = await fetch("https://api.example.com/users");
const data = await response.json();  // 解析 JSON
console.log(data);

// 完整错误处理
async function getData() {
  try {
    const res = await fetch("https://api.example.com/users");
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const data = await res.json();
    return data;
  } catch (error) {
    console.error("请求失败：", error);
  }
}

📤 POST — 发送数据

async function createUser(data) {
  const res = await fetch("https://jsonplaceholder.typicode.com/users", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(data)
  });
  return await res.json();
}

🔄 HTTP 方法总结

方法用途类比
GET获取数据查看菜单
POST创建数据点新菜
PUT更新数据（全部）换一道菜
PATCH更新数据（部分）改个口味
DELETE删除数据退菜

📌 要点总结

  • fetch 默认是 GET 请求
  • 需要 await res.json() 解析 JSON
  • 用 try/catch 处理网络错误
  • POST 需要设置 method、headers、body
  • 服务器返回的状态码：200=成功，201=创建成功，404=未找到，500=服务器错误
