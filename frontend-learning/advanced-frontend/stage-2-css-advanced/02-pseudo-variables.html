✨ CSS 伪元素与高级技巧

1️⃣ ::before 和 ::after — 伪元素

功能：在元素内容的前/后插入额外内容，不需要修改 HTML。

.element::before {
  content: "★";    /* 必须要有 content */
  color: gold;
  /* 配合 position 可以精确定位 */
}

.element::after {
  content: "";
  /* 空的 content 也可以用于装饰 */
}
CSS 伪元素是前端开发中非常强大且常用的技巧。

5️⃣ CSS 变量

:root {
  --primary: #e94560;       /* 定义变量 */
  --radius: 10px;
}

.box {
  color: var(--primary);    /* 使用变量 */
  border-radius: var(--radius);
}

🎨 使用 CSS 变量

修改 :root 中的 --primary 值，所有用到的地方自动更新！

💡 CSS 变量让主题切换变得极其简单，后面的 React 项目中会用到。

📊 常用伪元素 vs 伪类

类型写法作用
伪元素::before在元素内部前面插入内容
伪元素::after在元素内部后面插入内容
伪元素::first-letter第一个字母
伪元素::first-line第一行
伪元素::selection选中文字时的样式
伪类:hover鼠标悬停
伪类:nth-child(n)第 n 个子元素
伪类:not()排除选择
