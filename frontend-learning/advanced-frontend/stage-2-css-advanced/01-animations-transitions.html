🎬 CSS 动画与过渡

1️⃣ transition — 平滑过渡

功能：当元素属性发生变化时，平滑变化而不是瞬间跳变。

.box {
  transition: all 0.5s ease;
  /*         属性 时长   缓动函数 */
}
.box:hover {
  transform: rotate(180deg);
  border-radius: 50%;
}
◀ 悬停
⏳ 延迟

💡 把鼠标移上去试试！第二个有 0.2s 延迟。

2️⃣ @keyframes — 关键帧动画

功能：定义多步骤的复杂动画。

@keyframes bounce {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-40px); }
  100% { transform: translateY(0); }
}
.box {
  animation: bounce 1s ease infinite;
  /*        名称     时长 方式   循环 */
}
🎾 弹跳
💓 脉冲

📊 animation 完整属性

属性作用示例
animation-name动画名称bounce
animation-duration持续时间2s, 500ms
animation-timing-function速度曲线ease, linear, ease-in-out
animation-delay延迟开始1s
animation-iteration-count循环次数2, infinite
animation-direction播放方向normal, alternate, reverse
animation-fill-mode结束状态forwards, backwards
animation-play-state暂停/运行running, paused

📌 最佳实践

  • 优先使用 transform 和 opacity 做动画（性能好）
  • 避免动画 width、height（触发重排，卡顿）
  • 使用 will-change 提示浏览器优化
  • 移动端动画时长建议 200-400ms

✏️ 动手试试

1. 创建一个"心跳"动画（scale 缩放）
2. 做一个按钮悬停效果，带阴影变化
3. 尝试用多个关键帧（0%, 25%, 50%, 75%, 100%）

🎨 动画让页面"活"起来，但不要过度使用！
