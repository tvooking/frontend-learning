# 🚀 前端进阶学习项目

恭喜你完成了基础阶段的学习！这个进阶课程将带你进入现代前端开发的真实世界。

---

## 📚 学习路线

| 阶段 | 内容 | 前置要求 |
|------|------|----------|
| **Stage 1** ES6+ 现代 JavaScript | 箭头函数、Promise、async/await、Fetch API、模块化 | JS 基础 |
| **Stage 2** CSS 动画与进阶 | 动画、过渡、变换、伪元素、CSS 变量 | CSS 基础 |
| **Stage 3** 前端工程化 | npm、Vite 构建工具、Git 基础 | 终端基础操作 |
| **Stage 4** React 入门 | 组件、JSX、State、Props、Hooks | ES6+ 知识 |
| **Stage 5** 全栈实战 | Node.js + Express + React 完整项目 | 以上全部 |

---

## 🛠️ 新增工具

- **Node.js** — JavaScript 运行环境（Stage 3 开始需要）
- **VS Code** — 推荐编辑器（基础阶段应该已经用了）
- **终端 / Powershell** — 运行命令

---

## 🎯 学习目标

学完进阶课程后，你将能够：

1. 写出符合现代标准的 JavaScript 代码
2. 制作带有动画效果的网页
3. 使用构建工具和包管理器
4. 用 React 开发单页应用
5. 独立完成一个完整的全栈项目

> 💡 第1~2阶段仍然可以用浏览器直接打开 HTML 文件学习。
> 第3~5阶段需要安装 Node.js（后面会有教程）。

加油，你离专业前端工程师越来越近了！🔥
