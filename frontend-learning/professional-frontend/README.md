# 💼 职业前端工程师进阶课程

> 目标：掌握企业级前端开发能力，达到正式入职水准

---

## 📊 你需要掌握的能力矩阵

```
前端工程师能力模型
═══════════════════════════════════════════════
基础层     │ HTML语义化 · CSS布局 · JS核心
═══════════════════════════════════════════════
工具层     │ TypeScript · Git · 包管理器 · Vite
═══════════════════════════════════════════════
框架层     │ React · Next.js · Tailwind CSS
═══════════════════════════════════════════════
工程层     │ 测试 · CI/CD · 性能优化 · 部署
═══════════════════════════════════════════════
软技能     │ 代码评审 · 技术方案 · 团队协作
═══════════════════════════════════════════════
```

---

## 🗺️ 学习路线（12 周计划）

| 周次 | 阶段 | 产出物 |
|------|------|--------|
| 1-2 | **TypeScript 精讲** | 能用 TS 写 React 组件 |
| 3-4 | **React 深度实战** | 自定义 Hooks + 性能优化 |
| 5 | **路由 + 状态管理** | SPA 多页面应用 |
| 6 | **Tailwind CSS** | 不用手写 CSS 也能做好看 UI |
| 7-8 | **Next.js 全栈** | SSR + API Routes 完整应用 |
| 9 | **前端测试** | 单元测试覆盖率 > 80% |
| 10 | **工程化与部署** | CI/CD + 自动化部署上线 |
| 11-12 | **面试冲刺** | 刷题 + 简历 + 模拟面试 |
