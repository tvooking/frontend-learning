## 📝 简历指南

### 简历格式

- **一页** — 不要超过一页 A4
- **PDF** — 不要用 Word 格式
- **简洁** — 不要花哨的模板
- **数据化** — 用数字说话

### 简历内容模板

```
专业技能
- 熟练掌握 React / TypeScript / Next.js 开发
- 熟悉 Tailwind CSS / Zustand / React Query 等生态
- 了解 CI/CD 流程，有 Vercel 部署经验
- 良好的 Git 协作习惯，熟悉 Code Review 流程

项目经验

项目名称：电商管理系统
技术栈：React + TypeScript + Zustand + Tailwind CSS
- 独立负责前端架构设计，实现 20+ 个页面组件
- 使用 Zustand 管理全局状态，减少 60% 的不必要渲染
- 实现基于角色的权限管理，支持路由级权限控制
- 编写 50+ 个单元测试，覆盖率达到 85%

项目名称：个人博客
技术栈：Next.js + TypeScript + Tailwind + Prisma + PostgreSQL
- 实现 SSR/SSG 混合渲染策略，Lighthouse 评分 98
- 使用 Next.js API Routes 实现完整后端
- 集成 Markdown 编辑器，支持文章发布和分类管理
```

### 简历避坑

```
❌ "精通" — 改成"熟练使用"或"有丰富经验"
❌ "熟悉 Vue" — 如果只是看过文档，不要写
❌ "项目描述太长" — 每个项目 3-4 个要点即可
❌ "写太多技术名词" — 写你真正用过的
✅ 每个项目写清楚：你做了什么、用了什么技术、取得了什么成果
```

## 💡 面试技巧

### STAR 法则回答项目问题

```
S (Situation) — 项目背景
T (Task)      — 你的任务
A (Action)    — 你做了什么
R (Result)    — 取得了什么成果

示例：
S：之前的项目页面加载需要 5 秒
T：我是前端负责人，需要优化到 3 秒以内
A：实施了代码分割、图片懒加载、CDN 加速
R：加载时间降到 2 秒，Lighthouse 评分从 65 提升到 92
```

### 不会的问题怎么办

```markdown
1. 诚实说"不太清楚"
2. 说你知道的相关知识
3. 表达学习意愿

"这个问题我确实不太了解，
  不过我对 XX 有一些了解，
  您能给我讲讲吗？我也想学习一下。"
```

## 🚀 找工作行动计划

### 第 1-2 周：准备
- 完成本课程的所有内容
- 用 Next.js 做一个完整的个人项目
- 完善 GitHub，提交有质量的代码
- 写好简历

### 第 3-4 周：投递
- 每天投 5-10 家
- 记录投递的公司和岗位
- 每次面试后复盘

### 第 5-6 周：面试
- 刷 LeetCode 简单/中等题
- 准备系统设计题
- 准备反问问面试官的问题

### 反问面试官的问题

```
- 团队的技术栈是什么？
- 目前团队多少人？前后端比例？
- 项目目前处于什么阶段？
- 对新人的培养机制是怎样的？
- 代码评审流程是怎么样的？
- 加班情况如何？
```
