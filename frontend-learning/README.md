# 🎨 零基础前端学习项目

欢迎来到前端开发的世界！本项目专为**零基础**学习者设计，循序渐进，带你从 HTML → CSS → JavaScript → 独立完成一个个人主页。

---

## 📚 学习路线

| 阶段 | 内容 | 目标 |
|------|------|------|
| **第1阶段** HTML 基础 | 标签、语义化、布局 | 能搭建网页骨架 |
| **第2阶段** CSS 基础 | 样式、盒模型、Flex/Grid | 能美化网页布局 |
| **第3阶段** JavaScript 基础 | 变量、函数、DOM 操作 | 能给网页添加交互 |
| **第4阶段** 综合实战 | 个人主页项目 | 独立完成一个完整作品 |

---

## 🚀 学习方式

1. 按编号顺序学习每个文件
2. 在每个 HTML 文件中用浏览器直接打开（双击即可）
3. 修改代码观察变化，大胆尝试
4. 每节课后有"动手试试"小练习

---

## 🛠️ 所需工具

- **浏览器** Chrome / Edge（推荐）
- **编辑器** VS Code（推荐）或记事本
- **不需要** 安装任何服务器或环境

祝学习愉快！🎉
